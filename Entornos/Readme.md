## 👋 Presentación

En esta sección se presentan los principales entornos de ejecución que se pueden utilizar durante el curso **Fundamentos en R y Python**.

Un entorno de ejecución es el espacio donde escribimos, ejecutamos y organizamos nuestro código. Algunos funcionan directamente en el navegador, mientras que otros requieren instalación en el computador.

El objetivo es que cada estudiante conozca diferentes alternativas para trabajar con R y Python, tanto en la nube como de manera local.

---

## 🧭 ¿Qué entorno usar?

| Lenguaje | Entorno recomendado | Uso principal |
|---|---|---|
| R | Posit Cloud | Trabajar con RStudio desde el navegador |
| R | RStudio Desktop | Trabajar con R instalado en el computador |
| Python | Google Colab | Trabajar con notebooks en la nube |
| Python | Jupyter Notebook | Trabajar con notebooks localmente |
| R y Python | VS Code | Editar scripts y organizar proyectos |
| R y Python | GitHub Codespaces | Ejecutar proyectos desde GitHub en la nube |
| Python | Kaggle Notebooks | Analizar datos y usar notebooks en la nube |
| R y Python | Binder | Ejecutar notebooks desde repositorios públicos |

# ☁️ Entornos en la nube

## 📊 Posit Cloud

[![Posit Cloud](https://img.shields.io/badge/Posit_Cloud-RStudio-447099?style=for-the-badge&logo=posit&logoColor=white)](https://posit.cloud/)

**Posit Cloud** permite trabajar con RStudio desde el navegador, sin necesidad de instalar R ni RStudio en el computador.

Es una buena opción para estudiantes que están comenzando porque facilita el acceso a un entorno de trabajo ya configurado.

### Uso recomendado

- Trabajar ejercicios introductorios de R.
- Crear scripts en R.
- Importar y analizar bases de datos.
- Usar paquetes como `tidyverse`, `readxl`, `ggplot2` y otros.

### Enlace

👉 [Ir a Posit Cloud](https://posit.cloud/)

---

## 🐍 Google Colab

[![Google Colab](https://img.shields.io/badge/Google-Colab-F9AB00?style=for-the-badge&logo=googlecolab&logoColor=white)](https://colab.research.google.com/)

**Google Colab** permite escribir y ejecutar código de Python directamente desde el navegador mediante notebooks.

Es una de las herramientas más prácticas para iniciar en Python porque no requiere instalación y permite combinar código, texto, gráficos y resultados en un mismo documento.

### Uso recomendado

- Aprender sintaxis básica de Python.
- Trabajar con notebooks.
- Usar librerías como `pandas`, `numpy`, `matplotlib` y `seaborn`.
- Desarrollar ejercicios de análisis de datos.

### Enlace

👉 [Ir a Google Colab](https://colab.research.google.com/)

---

## 📓 Jupyter Notebook / JupyterLab

[![Jupyter](https://img.shields.io/badge/Jupyter-Notebook-F37626?style=for-the-badge&logo=jupyter&logoColor=white)](https://jupyter.org/)

**Jupyter** es un entorno interactivo que permite combinar código, texto, ecuaciones, gráficos y resultados.

Se usa principalmente con Python, aunque también puede utilizarse con otros lenguajes como R, Julia y Scala.

### Uso recomendado

- Trabajar notebooks de Python.
- Documentar ejercicios paso a paso.
- Combinar explicación, código y resultados.
- Desarrollar análisis reproducibles.

### Enlaces

👉 [Ir a Jupyter](https://jupyter.org/)  
👉 [Probar Jupyter en línea](https://jupyter.org/try)  
👉 [Instalar Jupyter](https://jupyter.org/install)

## 🧑‍💻 Visual Studio Code Web

[![VS Code Web](https://img.shields.io/badge/VS_Code-Web-007ACC?style=for-the-badge&logo=visualstudiocode&logoColor=white)](https://vscode.dev/)

**Visual Studio Code Web** permite abrir y editar archivos directamente desde el navegador.

Es útil para revisar archivos, editar scripts y trabajar con repositorios. Sin embargo, para ejecutar código puede requerir herramientas adicionales como GitHub Codespaces, una conexión remota o la versión de escritorio.

### Uso recomendado

- Editar archivos `.R`, `.py`, `.md` y `.ipynb`.
- Revisar repositorios de GitHub.
- Modificar scripts desde el navegador.
- Trabajar con proyectos pequeños.

### Enlaces

👉 [Ir a VS Code Web](https://vscode.dev/)  
👉 [Documentación de VS Code Web](https://code.visualstudio.com/docs/setup/vscode-web)

---

## 🐙 GitHub Codespaces

[![GitHub Codespaces](https://img.shields.io/badge/GitHub-Codespaces-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/features/codespaces)

**GitHub Codespaces** permite crear un entorno de desarrollo completo en la nube, conectado directamente con un repositorio de GitHub.

Es una opción útil cuando se quiere trabajar con proyectos completos, carpetas organizadas, terminal, instalación de paquetes y control de versiones.

### Uso recomendado

- Trabajar directamente desde un repositorio de GitHub.
- Ejecutar scripts de Python o R en la nube.
- Usar terminal.
- Desarrollar proyectos reproducibles.

### Enlace

👉 [Ir a GitHub Codespaces](https://github.com/features/codespaces)

---

## 📈 Kaggle Notebooks

[![Kaggle](https://img.shields.io/badge/Kaggle-Notebooks-20BEFF?style=for-the-badge&logo=kaggle&logoColor=white)](https://www.kaggle.com/code)

**Kaggle Notebooks** permite trabajar con notebooks en la nube, especialmente para análisis de datos, ciencia de datos y aprendizaje automático.

Tiene la ventaja de contar con muchas bases de datos públicas disponibles dentro de la misma plataforma.

### Uso recomendado

- Practicar análisis de datos.
- Usar bases de datos públicas.
- Ejecutar notebooks de Python.
- Explorar ejemplos de ciencia de datos.

### Enlace

👉 [Ir a Kaggle Notebooks](https://www.kaggle.com/code)

---

## 🔗 Binder

[![Binder](https://img.shields.io/badge/Binder-Reproducible_Notebooks-F37626?style=for-the-badge&logo=jupyter&logoColor=white)](https://mybinder.org/)

**Binder** permite ejecutar notebooks desde repositorios públicos, creando un entorno reproducible en línea.

Es útil cuando se quiere compartir un repositorio con notebooks que otros estudiantes puedan ejecutar sin instalar nada.

### Uso recomendado

- Compartir notebooks reproducibles.
- Ejecutar ejercicios desde GitHub.
- Crear materiales de clase interactivos.
- Facilitar el acceso a código sin instalación local.

### Enlace

👉 [Ir a Binder](https://mybinder.org/)

---

## ⚡ Replit

[![Replit](https://img.shields.io/badge/Replit-Python-667881?style=for-the-badge&logo=replit&logoColor=white)](https://replit.com/languages/python3)

**Replit** permite escribir, ejecutar y compartir código directamente desde el navegador.

Puede ser útil para ejercicios pequeños de programación, especialmente cuando se quiere practicar sintaxis básica de Python.

### Uso recomendado

- Ejercicios cortos de Python.
- Práctica de condicionales, ciclos y funciones.
- Compartir código de manera sencilla.
- Programación básica desde el navegador.

### Enlace

👉 [Ir a Replit Python](https://replit.com/languages/python3)

# 💻 Entornos locales

## 📊 RStudio Desktop

[![RStudio](https://img.shields.io/badge/RStudio-Desktop-75AADB?style=for-the-badge&logo=rstudioide&logoColor=white)](https://posit.co/downloads/)

**RStudio Desktop** es uno de los entornos más utilizados para trabajar con R desde el computador.

Para usarlo se recomienda instalar primero R y luego RStudio.

### Uso recomendado

- Trabajar con R de manera local.
- Crear scripts `.R`.
- Organizar proyectos.
- Instalar y administrar paquetes.
- Desarrollar análisis reproducibles.

### Enlaces

👉 [Descargar R](https://cran.r-project.org/)  
👉 [Descargar RStudio Desktop](https://posit.co/downloads/)

## 🧑‍💻 Visual Studio Code Desktop

[![VS Code](https://img.shields.io/badge/VS_Code-Desktop-007ACC?style=for-the-badge&logo=visualstudiocode&logoColor=white)](https://code.visualstudio.com/)

**Visual Studio Code** es un editor de código muy utilizado para trabajar con distintos lenguajes de programación, incluyendo Python y R.

Permite instalar extensiones, trabajar con carpetas, usar terminal, conectarse con GitHub y desarrollar proyectos completos.

### Uso recomendado

- Escribir scripts de Python.
- Escribir scripts de R.
- Organizar proyectos.
- Trabajar con Git y GitHub.
- Usar terminal integrada.

### Enlace

👉 [Descargar Visual Studio Code](https://code.visualstudio.com/)

## 🐍 Python local

[![Python](https://img.shields.io/badge/Python-Local-3776AB?style=for-the-badge&logo=python&logoColor=white)](https://www.python.org/downloads/)

También es posible instalar Python directamente en el computador.

Esta opción es útil para quienes quieran avanzar hacia proyectos más completos, automatización, análisis de datos, econometría, machine learning o desarrollo de aplicaciones.

### Uso recomendado

- Ejecutar scripts `.py`.
