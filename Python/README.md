# Módulo de Python

## Presentación

Este módulo introduce el uso de **Python** como lenguaje de programación para el análisis de datos.

Python es uno de los lenguajes más utilizados en ciencia de datos, inteligencia artificial, automatización, análisis estadístico, economía aplicada, finanzas y visualización de información. Su sintaxis clara y su amplia comunidad lo convierten en una herramienta muy útil para quienes inician en programación.

En este módulo se trabajará desde los fundamentos del lenguaje hasta el uso de librerías básicas para importar, limpiar, analizar y visualizar datos.

---

## Objetivo del módulo

Desarrollar habilidades básicas en Python para resolver ejercicios de programación, manipular bases de datos y realizar análisis descriptivo de información.

---

## Resultados de aprendizaje

Al finalizar este módulo, el estudiante podrá:

- Comprender la sintaxis básica de Python.
- Crear variables y trabajar con distintos tipos de datos.
- Utilizar listas, tuplas, diccionarios y estructuras de control.
- Escribir condicionales y ciclos.
- Crear funciones simples.
- Importar y manipular bases de datos con `pandas`.
- Calcular estadísticas descriptivas.
- Construir gráficos básicos.
- Trabajar en notebooks de Google Colab o Jupyter.
